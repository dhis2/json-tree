# RFC 8259 compatibility

The library is generally compatible with the rules defined by RFC 8259.

## Specific behaviour

- **Duplicate keys**: consistently returns the entry that is encountered first
  (note that this is not necessarily the first if doing advanced iteration from
  some mid-point).
- **Member ordering**: always reflects the order in the JSON source.
- **Leading zeros**: are permitted.
- **Trailing commas**: are permitted.
- **Unpaired surrogates**: cause errors.
- **BOM**: is skipped.
